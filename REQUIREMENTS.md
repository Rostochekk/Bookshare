## Функціональні вимоги

### FR-01: Авторизація
- Система має підтримувати реєстрацію через email та пароль
- Система має підтримувати вхід через Google OAuth 2.0
- Паролі мають зберігатись у хешованому вигляді (bcrypt)
- Система має підтримувати скидання паролю через email

### FR-02: Каталог книг
- Користувач може переглядати всі доступні книги
- Система має підтримувати пошук за назвою та автором
- Система має підтримувати фільтрацію за категорією та станом книги
- Доступні категорії: навчальна, художня, технічна, наукова, література, історія, математика, програмування

### FR-03: Управління оголошеннями
- Авторизований користувач може додавати книгу з полями: назва, автор, категорія, стан, опис, обкладинка
- Користувач може редагувати лише власні оголошення
- Користувач може видаляти лише власні оголошення
- Обкладинка книги завантажується як файл (зображення)

### FR-04: Особистий кабінет
- Користувач може переглядати список власних книг
- Користувач може змінювати аватар профілю

### FR-05: Чат
- Користувач може написати власнику книги
- Система автоматично надсилає перше повідомлення з назвою книги
- Не можна писати самому собі
- Підтримка відправки зображень у повідомленнях
- Відстеження прочитаних повідомлень

### FR-06: Адмін-панель
- Адміністратор може переглядати список усіх користувачів та книг
- Адміністратор може блокувати/розблоковувати користувачів
- Адміністратор може видаляти книги та користувачів
- Доступ лише з роллю `admin`

## Нефункціональні вимоги

### NFR-01: Продуктивність
- API має відповідати протягом 500 мс за нормальних умов
- База даних SQLite достатня для навчального навантаження

### NFR-02: Безпека
- Паролі зберігаються виключно у хешованому вигляді
- Редагування/видалення книги перевіряє owner_id
- Адмін-роути захищені middleware `requireAdmin`

### NFR-03: Доступність
- Застосунок розгорнуто на Render (безкоштовний план)
- Можливий cold start до 30–60 секунд після неактивності

### NFR-04: Тестування
- Покриття автоматизованими тестами: авторизація, CRUD книг, пошук
- Кількість тестів: 23 (Jest + Supertest)
